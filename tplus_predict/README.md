# T+ v0.4 automated forecast baseline

Strictly pre-match historical market benchmark, **not** an independent predictive model or betting system.
Reads only public `model_feed/latest.json` generated by `T+ publish sanitized model feed`.
Writes `predictions/latest.json`, `status.json`, `records/`, `freezes/`, and `evaluation.json`.
A freeze is recorded only for a real execution in the final 15 minutes before kickoff; missed runs cannot be retroactively converted to freezes. Historical snapshots are immutable by input hash.

## What is intentionally not implemented
- Automated ChatGPT conversation, X-laoshi, 001–005, Claude, Gemini execution. Those require separately deployed model API workers and credentials, which are **not** included or impersonated here.
- xG, injuries or lineups: not in T-only public feed.
- Automatic final-result ingestion: evaluation is only possible after an independently verified, licensed source provides outcomes. A valid `predictions/results_verified.json` uses `{results:[{t_match_id,home_goals,away_goals,status:"FT",source_url,verified_at_utc}]}`; do not trust unverified results or post-match features.

## Integrity
- Exact kickoff converted from China-local date and time; ambiguous source capture time explicitly carries its caveat.
- No after-kickoff input or result leakage; all UTC comparisons are timezone aware.
- Predictions are not investment recommendations; probability accuracy requires out-of-sample scoring.
